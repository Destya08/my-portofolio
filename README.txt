PORTOFOLIO NETWORKING — CARA PAKAI

1. Ekstrak folder portfolio-networking.
2. Buka folder tersebut di Visual Studio Code.
3. Buka index.html di browser untuk melihat website.
4. Ubah tulisan "Nama Kamu", email, dan tautan LinkedIn/GitHub di index.html.
5. Untuk foto profil, masukkan foto dengan nama foto-profil.jpg ke folder images.
6. Ilustrasi projek masih berupa contoh desain. Ganti/ tambahkan screenshot asli hasil projekmu nanti.
7. Urutan halaman: pembuka, profil + foto, kontak, keahlian, projek, sertifikat/pengalaman.

File utama:
- index.html = struktur dan isi website
- style.css = tampilan, warna, layout, dan responsif

Catatan: font dari Google Fonts memerlukan koneksi internet. Tanpa internet website tetap berjalan menggunakan font cadangan.
